# 画像の出典

利用者の「既存アプリに入っているデータを使う」という指示に基づき、旧アプリの画像をバイト列を変えずに再利用しています。出典ファイルとSHA-256はassets-manifest.jsonに記録しました。

- アプリアイコン：既存Android用512×512 PNG。
- ワードマーク：既存の黒・白の「アーカイブ」。
- カテゴリ：14分類、その他のみ明暗2種類。
- Googleマーク：既存SVG。Googleログインボタンのみに使用。

新しいイラスト、教員画像、教員情報、本番作品PDFは含めません。作品タイトル・班名・概要は架空のUI fixtureです。

画像の個別著作者・ライセンス表記は今回新たに確定していません。アプリ内での再利用指示と、一般への素材の再配布許諾は区別します。公開リポジトリ化の前に権利を確認し、必要な表記を追加します。Googleマークの変更は行っていません。
