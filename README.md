# 探究アーカイブ PWA

学校のGoogleアカウントで探究作品を探し、PDFを閲覧するWebアプリ。Vite＋React＋TypeScriptで新規実装する計画です。現時点ではアプリ実装に着手していません。

## 公開アプリの範囲

- スマートフォン・iPad・PCに対応するギャラリー型UI。
- ゴシック体、利用許諾された既存画像。
- 認証付きAPIによる検索・作品閲覧・お気に入り・履歴・通知。
- PDFダウンロード、アプリ内の72時間保存。

APIサーバー・管理処理・全体の運用仕様は別の非公開管理リポジトリで扱います。このアプリは単独clone・buildができる構成を目標にし、privateディレクトリを直接importしません。

依存関係、起動・テスト・環境設定は基盤実装時に追記します。秘密鍵・実利用者データ・作品PDFはこのリポジトリへ含めません。
